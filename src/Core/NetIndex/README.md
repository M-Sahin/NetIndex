# NetIndex (Prefix Reservation)

This package exists only to reserve the `NetIndex.*` package prefix on NuGet.org.

It intentionally contains no functional runtime assemblies.

If you are looking for actual functionality, use one of the concrete packages such as:

- `NetIndex.Core`
- `NetIndex.Core.Abstractions`
- `NetIndex.Storage.Sqlite`
- `NetIndex.Providers.Ollama`

[Full documentation and source →](https://github.com/M-Sahin/NetIndex#readme)
