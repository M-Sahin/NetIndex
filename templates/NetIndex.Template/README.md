# NetIndex.Template

`dotnet new` project template that scaffolds an ASP.NET Core 9 RAG app pre-wired for Azure OpenAI + pgvector, with a commented Ollama + SQLite swap block for local development. Installs once, scaffold as many projects as you need.

```bash
dotnet new install NetIndex.Template
dotnet new netindex -n MyRagApp
```

[Full documentation and source →](https://github.com/M-Sahin/NetIndex#readme)
